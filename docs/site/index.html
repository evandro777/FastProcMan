FastProcMan

A light and fast process manager: find what is eating CPU or memory, and quit it.

GitHub · Releases

Early version. Tested on Linux Mint Cinnamon. Use the AppImage: inside a Flatpak sandbox the app only sees its own processes.

What it does

Written in Rust with Slint, software rendering only, no async runtime. About 30 MB of RAM (about 50 MB with an NVIDIA card) and about 3% of one core at the default 1 s refresh.

Sort and filterCPU, memory, name or PID, straight from /proc.
Quit or force quitOne click (force quit is for a program that does not respond), or Delete and Shift+Delete. Other users' processes ask for a password through polkit.
Suspicious onesDeleted programs and programs running from /tmp are flagged, with a filter.
Slowdown warningA banner names what is filling the memory, disk or CPU before the desktop freezes. The limits are yours to change in Preferences.
GraphsOne minute of CPU, memory, network, GPU and disk activity.

Install with Flatpak (updates itself)

This remote keeps FastProcMan updated with flatpak update and your software centre:

flatpak remote-add --system --if-not-exists fastprocman https://evandro777.github.io/FastProcMan/fastprocman.flatpakrepo
flatpak install --system fastprocman io.github.evandro777.FastProcMan

Use --system: Linux Mint's Update Manager only looks at system-wide Flatpaks. The runtime comes from Flathub. The remote is GPG-signed, but the key lives in the source repository, so it is only as trustworthy as that.

Or the AppImage

Download FastProcMan-<version>-x86_64.AppImage from the latest release, chmod +x it and run it. It uses the fontconfig, xkbcommon and X11 libraries already on your system, and carries update information, so AppImageUpdate, Gear Lever or AppManager download only what changed.

Run one of the two, not both: they use different data folders.
